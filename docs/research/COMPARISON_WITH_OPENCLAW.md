# 🥊 MiniMonkey vs OpenClaw 深度对比分析

## 📋 项目概况

### MiniMonkey（本项目）

**定位**: 专业级桌面 AI Agent 平台  
**技术栈**: Bun + TypeScript + Vue 3 + Neutralino.js  
**核心特性**: MCP 协议集成、AI 任务规划、Bridge 桥接层、企业级安全认证  

### OpenClaw

**定位**: 开源自主 AI 助手（前身为 Clawdbot/Moltbot）  
**技术栈**: Node.js + Python + Discord/Telegram 机器人  
**核心特性**: 消息应用集成、基础自动化、本地部署
