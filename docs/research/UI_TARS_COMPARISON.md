# 🚀 UI-TARS-desktop vs MiniMonkey 深度对比分析

## 📋 项目概况

### UI-TARS-desktop (字节跳动)

**定位**: 开源多模态 AI Agent 栈  
**技术栈**: Python + PyTorch + 自研多模态模型  
**核心特性**: 视觉 - 语言模型、GUI 理解、自我学习  
**GitHub Stars**: 12k+ (快速增长)  
**发布时间**: 2024 年底  

### MiniMonkey (本项目)

**定位**: 专业级桌面 AI Agent 平台  
**技术栈**: Bun + TypeScript + Vue 3 + Neutralino.js  
**核心特性**: MCP 协议、AI 任务规划、企业级安全  
**GitHub Stars**: 新兴项目  
**发布时间**: 持续迭代中
